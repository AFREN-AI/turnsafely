# Contributing

Keep this tool focused on reproducible, human-reviewed safety metrics for interview-style transcription.

- Add tests for each changed public function.
- Do not add personal data, third-party audio, or unlicensed transcripts.
- Keep labels explicit and reviewer-supplied. Do not add automatic hiring scores or candidate rankings.
- Document normalization rules and metric denominators.
- Run `python -m unittest discover -s tests` before submitting a change.
- See [DATA.md](DATA.md) for annotation and licensing requirements.
